UE4M3 values y where y rounds, R(y) everything that rounds there the values after scaling where the scaled y actually rounds

On a log scale, every binade of N holds the same 8 values.

A value \(y\) rounds to its nearest value, \(R(y)\). The shaded cell is everything that rounds there.

Multiplying by 2 shifts everything by one binade. N lands on itself, so the nearest value moves along: \(R(2y) = 2R(y)\).

The same holds for every power of two: \(R(2^k y) = 2^k R(y)\).

A general factor shifts by a fraction of a binade. N does not land on itself: \(R(1.1\,y) = 1.75\), not \(1.1\,R(y) \approx 1.79\).

At the bottom, the subnormal values S have fewer points per binade, so the pattern breaks.

Halving a value moves it into S, where it rounds differently: \(R(y/2) \ne R(y)/2\).
